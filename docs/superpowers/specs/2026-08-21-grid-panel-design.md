# 격자 만들기 설계

작성일: 2026-08-21
상태: 구현 완료

## 무엇을 만드는가

지도에 올라와 있는 **포인트 레이어를 정사각 격자로 묶어** 칸마다 집계한 폴리곤 레이어를 만든다.
공공데이터 화면에만 있던 격자 집계를 `벡터 분석 ▸ 격자 만들기` 로 꺼냈다.

공공데이터 설계(2026-08-12)에서 "격자 집계는 공공데이터 화면 안에서만. 집계 로직은
독립 모듈로 두어 나중에 노출만 하면 되게 한다"고 정해 둔 것을 실행한 것이다.

## 확정된 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 메뉴 위치 | `벡터 분석 ▸ 격자 만들기` (버퍼 분석 위) | 점을 다루는 기능끼리 묶는다 |
| 대상 레이어 | **점 피처가 있는 벡터 레이어만** | 선·면을 격자로 묶는 건 수업에서 의미가 흐리다 |
| 격자 크기 | 500m·1km·5km·10km + **직접 입력(m)** | 사용자 선택. "2km로 해보자" 같은 요구를 바로 받는다 |
| 최소 크기 | 10m | 50m 같은 값으로 칸이 폭발하는 사고를 막는다 |
| 집계 방식 | 개수 / 합계 / 평균 | 공공데이터 격자와 동일 |
| 빈 칸 표시 | 체크박스로 선택, **기본은 꺼짐** | 점이 없는 칸까지 그리면 폴리곤이 크게 는다. 다만 '없음'과 '0'을 구분해 보여줘야 할 때가 있어 고를 수 있게 했다 |
| 산출물 | 폴리곤 레이어 + 단계구분도 범례 | 공공데이터 격자와 **완전히 같다** — 저장·복원·주제도 편집이 그대로 따라온다 |
| 원본 레이어 | 그대로 둔다 | 공공데이터는 중간 포인트를 남기지 않지만, 여기선 이미 있는 레이어가 원본이다 |

## 구성 요소

| 구성 | 위치 | 성격 |
|---|---|---|
| 격자 집계 | `src/tools/gridAggregate.js` | 기존. 손대지 않았다 |
| 격자 레이어 만들기 | `src/tools/gridLayer.js` (신규) | `publicDataLoad.js` 에 묶여 있던 것을 꺼냈다. 공공데이터와 패널이 **같은 함수**를 쓴다 |
| 점 뽑기·입력 검증 | `src/tools/gridPoints.js` (신규) | 순수 로직. 피처→점, 격자 크기 파싱, 숫자 속성 고르기 |
| 패널 | `src/ui/panels/GridPanel.js` (신규) | `BufferPanel` 과 같은 모달 구조, 레이어 드롭다운은 공통 규칙(`layerSelect.js`) |
| 스타일 | `src/styles/main.css` | 버퍼 모달 규칙에 `.grid-*` 선택자를 **나란히 붙였다**(복제하지 않음) |

## 안전장치

- 칸 수를 미리 추정해 **20,000칸**(`GRID_CELL_LIMIT`)을 넘으면 만들기 전에 막는다.
- 합계·평균인데 숫자 속성이 없으면 만들지 않고 안내한다.
- MultiPoint 는 점 하나하나를 따로 센다 — 한 피처가 여러 자리에 있으면 그게 맞다.
- 빈 칸을 포함해도 `estimateCellCount` 가 이미 **사각 범위 전체**를 세므로 20,000칸 상한이 그대로 걸린다.
- 빈 칸의 값은 개수일 때 0, 합계·평균일 때 null 이다 — '값이 0'과 '잴 값이 없음'을 섞지 않는다.

## 하지 않는 것

- 선·면 레이어의 중심점을 격자로 묶는 기능.
- 격자 칸에서 원본 점 목록을 되짚어 보는 기능.
