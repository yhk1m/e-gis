# 레이어 다중 선택과 한꺼번에 작업 (2026-11-09)

사용자 결정(2026-11-09): 동시 작업 4종 전부(스타일, 내보내기와 복사, 속성 계산, 분석), 태블릿은 「여러 개 선택」 버튼, 내보내기는 zip 하나, 설계안 그대로 진행.

## 지금 있는 것
- `layerManager.selectedLayerIds`(Set), `selectLayerWithModifier(id, ctrl, shift)`, `getSelectedLayerIds()`, `clearSelection()`
- Ctrl/Shift 클릭, 드래그 박스(marquee) 선택, 2개 이상이면 `.layer-multi-select-info`(선택 해제, 삭제)
- 다중 우클릭 메뉴: 선택 레이어로 이동, 모두 표시, 모두 숨기기, 선택 레이어 삭제
- 확인 창은 `utils/dialogs.js`(showConfirm 등). 브라우저 기본 창 쓰지 않기(전체화면 풀림)

## 1. 고르기 (선택 모드)
- 레이어 패널 머리줄에 「여러 개 선택」 토글 버튼(선 SVG 아이콘 + 글자, 이모지 금지).
- 켜면 레이어 줄마다 선택 체크 칸이 보이고, 줄을 누르면 선택에 더하거나 뺀다(Ctrl 클릭과 같음). 가시성 체크박스와 헷갈리지 않게 모양을 구분.
- 끄면 선택이 하나(마지막 기준 또는 없음)로 돌아간다. Esc 로도 끔.
- 데스크톱 Ctrl/Shift 클릭은 그대로.

## 2. 작업 줄 (2개 이상 선택 시)
기존 `.layer-multi-select-info` 를 넓혀 「N개 선택됨」 + 버튼: 스타일, 복사, 내보내기(zip), 속성 계산, 이동, 보이기/숨기기, 삭제, 선택 해제. 좁은 폭에선 줄바꿈(아이콘 + 짧은 글자). 다중 우클릭 메뉴에도 같은 항목 추가.

## 3. 스타일 한꺼번에
- `showColorPicker(layerIdOrIds)` 가 배열을 받는다. 창은 첫 레이어 값을 보여 주고, 바꾸는 값은 고른 레이어 모두에 `layerManager.setLayer*` 로 적용.
- 지오메트리가 섞이면 공통 항목만(선 색, 면 색/불투명도, 선 굵기, 선 모양 등 모든 종류에 의미 있는 것). 점 크기는 모두 점일 때만.
- 스타일을 못 바꾸는 레이어(흐름, 도형표현도, 래스터, 히트맵)는 건너뛰고 창 위에 「N개는 스타일을 바꿀 수 없어 제외」 한 줄.

## 4. 복사, 내보내기
- 복사: 고른 순서대로 기존 duplicate 를 각각 실행.
- 내보내기: `src/utils/exportLayersZip.js` 의 `exportLayersZip(layerIds)` — 벡터 레이어마다 `<이름>.geojson`(EPSG:4326, 단일 내보내기와 같은 방식) 을 jszip 으로 묶어 `레이어_N개.zip` 저장. 이름 겹치면 `_2` 붙임. 벡터가 아닌 레이어는 건너뛰고 알림.

## 5. 분석, 속성 계산 한꺼번에
- `utils/layerSelect.js` 에 `MULTI_LAYER_VALUE = '__selected__'`, `buildLayerOptions` 에 옵션 `multiIds`(지원되는 선택 레이어 id 배열, 2개 이상일 때만) → 맨 위에 「선택한 레이어 N개 모두」 항목. 패널을 열 때 다중 선택이 2개 이상이고 지원 레이어가 2개 이상이면 이 항목을 미리 고른다.
- 대상 패널: 버퍼, 보로노이, 격자, 히트맵, 필드 계산기. 실행하면 레이어마다 따로 실행(결과 레이어도 따로), 끝나고 「N개 레이어에 적용」 상태 메시지. 하나가 실패해도 나머지는 계속, 실패한 레이어 이름을 마지막에 한 번만 알림.
- 필드 계산기: 필드 목록은 고른 레이어들의 공통 필드. 새 필드 이름은 모두에 추가.
