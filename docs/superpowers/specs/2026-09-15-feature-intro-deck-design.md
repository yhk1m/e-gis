# e-GIS 기능 소개 프레젠테이션(HTML 덱) 설계

작성일: 2026-09-15

## 목적

교사 연수·학회 발표 자리에서 e-GIS(웹)의 기능을 소개하는 HTML 슬라이드 덱. 내용은 `/guide`(`docs/사용설명서.md`) 1부를 바탕으로 하되, 설명 사이사이에 실제 프로그램 캡처를 넣어 구체화한다.

범위는 **1부 e-GIS 웹만**. e-GIStory는 마지막 한 장에서 연동 흐름만 언급한다.

## 결과물

```
바탕화면\e-GIS 기능 소개\
  e-GIS_기능소개.html     슬라이드 본체 (단일 HTML, CSS·JS 인라인)
  images\                  캡처 PNG, 파일명 = 슬라이드번호-기능명 (예: 26-buffer.png)
```

- 6월 연수 덱(`바탕화면\e-GIS 실습 (빛길지리)\`)과 같은 폴더+images 방식. 캡처를 나중에 갈아 끼우기 쉽다.
- 글꼴은 Pretendard(CDN, 없으면 시스템 sans-serif 폴백). 색 토큰은 6월 덱 계승: `--blue #024AD8`, `--blue-bright #296EF9`, `--blue-soft #C9E0FC`, `--ink #1A1A1A`, `--gray #636363`, `--line #C2C2C2`, `--bg-1 #F7F7F7`.
- 이모지 금지. 아이콘은 선 SVG.

## 슬라이드 레이아웃 4종

1. **표지/마무리** — 큰 제목 + 파란 태그 + 부제.
2. **기능(기본)** — 상단 메타 바(섹션 태그 · 페이지 번호). 왼쪽 38%: 기능 이름, 한 줄 요약, 진입 경로(`메뉴 → 벡터 분석 → 버퍼 분석`), 핵심 불릿 3~4개, 수업 활용 한 줄(파란 연한 상자). 오른쪽 62%: 캡처(그림자·둥근 모서리).
3. **캡처 강조** — 결과가 지도 전체인 기능(단계구분도·도형표현도·카토그램·흐름도·3D·지형음영·등시선)은 캡처를 폭 100%로 크게, 설명은 아래 한 줄 띠와 오른쪽 좁은 열.
4. **표/텍스트** — 목차, 지원 형식 표, 좌표계 표, 단축키 표.

섹션 구분 슬라이드는 두지 않는다. 각 슬라이드 상단 태그에 `섹션명 · n/m`을 적어 위치를 알린다.

## 동작

- 키보드: `←` `→` `Space` `PgUp` `PgDn` 넘김, `Home` `End`.
- 오른쪽 아래 `23 / 45` 표시. 목차 항목 클릭, 상단 섹션 태그 클릭으로 그 섹션 첫 슬라이드 이동.
- URL 해시 `#23`으로 특정 슬라이드 열기, 이동 시 해시 갱신.
- 인쇄: `@page { size: landscape }`, 슬라이드마다 `page-break-after`, 화면용 네비 숨김 → Ctrl+P로 전체 PDF.
- 16:9 고정 비율 스테이지(1600×900 기준)를 창 크기에 맞춰 `scale()`.

## 캡처 규칙

- `npm run dev` → Chrome 확장으로 `http://localhost:5173` 열기, 창 크기 1600×900.
- 앱 로드 전 `localStorage.egis_last_visit = 오늘(KST)`을 넣어 조회수가 늘지 않게 한다.
- 밝은 테마, 기본 배경지도(5번 어두운 테마·12번 위성 제외).
- 데이터는 모두 내장 실습 데이터(대한민국 시도·시군구·서울 자치구, 시도별 인구·GRDP, 서울 스타벅스·의료복지시설 포인트, 시도간 인구이동 흐름, 시군구 DEM)와 공공데이터 탭 — 보는 사람이 따라 할 수 있는 상태만 보여준다.
- 한 세션에서 상태를 누적해 쓴다: 시도 + 인구 결합 → 필드 계산기 → 라벨 → 단계구분도 → 도형표현도 → 카토그램.
- 좌표계 확인 창(13)은 crs 근거가 없는 파일이 필요하다. 내장 시군구를 GeoJSON으로 내보낸 뒤 좌표를 EPSG:5179 값으로 바꾸고 crs 정보를 뺀 파일을 만들어 올린다. 재현이 어려우면 상태 표시줄의 좌표계 드롭다운 캡처로 대체한다.
- 지리참조(34)는 임의의 지도 이미지(프로젝트 `icon/` 또는 캡처한 지도 PNG)를 올려 GCP 2~3개를 찍은 상태를 찍는다.
- 로그인(42)은 로그인 창까지만. 계정으로 로그인하지 않는다.
- 캡처마다 이미지를 열어 확인한다. 잘린 패널·빈 지도·로딩 중 화면은 다시 찍는다.

## 검증

- 45장이 모두 있고 `images/` 파일이 각 슬라이드의 `<img src>`와 1:1로 대응하는지 스크립트로 확인.
- 브라우저에서 처음·중간·끝 슬라이드를 열어 레이아웃과 넘김을 확인, 인쇄 미리보기에서 페이지 나뉨 확인.
- 이모지 포함 여부 검사(정규식).
