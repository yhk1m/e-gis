## 슬라이드 형식

**실습 개요(46쪽)** — `table.grid` 재사용. 열: 번호 · 실습 · 데이터 · 익히는 기능 · 참고 쪽. 8행이 들어가야 하므로 `table.grid.mini`급 크기(18px)로.

**단계 슬라이드(홀수 쪽)** — 텍스트만, 목차와 같은 상자 없는 편집형.
- `.meta` 태그 + 쪽수, `h2` = `실습 ① 서울 자치구 고령화 단계구분도`(50px), 리드 한 줄 = 실습이 답하려는 질문.
- 리드 아래 `.data` 한 줄: 파란 라벨 `데이터` + 내용(예: `내장 면 → 서울 자치구 · 내장 속성 → 서울 자치구별 고령인구비율`).
- 본문 `.steps`: 2열 × 3행 그리드, 각 `.step` = 파란 큰 번호(`01`, 46px, 목차 `.n`과 같은 규격) + 굵은 동작(`.t`, 27px) + 회색 세부(`.d`, 19px, 메뉴 경로 · 설정값) + 끝에 `.ref` 쪽수. 항목 사이는 `--line-soft` 구분선, 카드 · 배경 없음. 5단계면 마지막 칸은 비운다.
- 새 CSS는 `.data` `.steps` `.ref` 셋뿐. 나머지는 기존 토큰 · 클래스.

**결과 슬라이드(짝수 쪽)** — 기존 캡처 슬라이드와 같은 `.body > .shot + .text`(캡처 왼쪽 62 · 텍스트 오른쪽 38, 위쪽 정렬).
- `h2` = `결과 읽기`, 리드 한 줄, `ul.points` 불릿: 지도에서 읽히는 것 2~3개 → `수업` 확장 1개 → `주의` 1개(막히기 쉬운 지점). 기존 슬라이드의 `수업` 표기 방식을 그대로 따른다.
- **실습 ⑤ 결과(56쪽)만 비교형**: 위에 캡처 2장을 나란히(각 ~700px, 캡션 `광주` / `서울`), 아래에 두 열 불릿(광주 읽기 / 서울 읽기). 캡처 높이는 400px 안팎.

문구 규칙은 [feedback-slide-tone] 그대로: 명사형 어미, 키워드 중심, "~합니다" 금지. 이모지 금지. 한국어 고아 글자 검사(마지막 줄 너비 < 2.6em) 통과.
